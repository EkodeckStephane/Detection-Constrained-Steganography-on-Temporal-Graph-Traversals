## Exact gap to test

The paper should end Related Work with the following bounded gap, subject to the final search audit:

> Existing work separately establishes distribution-aware generative coding, graph/path carriers, adaptive steganographic optimization, and behavioral covert channels. The unresolved problem addressed here is how to control covert payload when an emitted temporal-graph action becomes part of the causal state and therefore changes the future admissible support, while keeping passive decoding synchronized and selecting the operating policy under an explicit empirical detector budget.

## Required same-protocol baselines

The final experiments must include, where technically valid under the same temporal candidate set:

1. natural cover / no embedding;
2. random admissible continuation;
3. fixed entropy threshold;
4. ordinary local range/arithmetic coding without detector-aware control;
5. hand-tuned fuzzy controller;
6. optimized Takagi-Sugeno controller;
7. at least one distribution-preserving or distribution-copy/coupling-inspired baseline adapted without changing the carrier semantics;
8. optional learned constrained policy as a capacity/security reference.

A baseline that uses a different carrier (e.g., bits per static graph edge) can be reported only as contextual evidence, not as a direct performance ranking.

## Applied Soft Computing positioning rule

The ASOC-specific scientific story is:

- **soft-computing contribution:** interpretable optimized fuzzy/hybrid control under uncertainty and partial observability;
- **security application:** covert temporal-graph communication under steganalysis constraints;
- **system-control contribution:** sequential EMBED/COVER/PAUSE/STOP decisions with causal state evolution;
- **multi-objective contribution:** capacity, detectability, synchronization, and abstention are optimized/evaluated jointly.

The fuzzy controller must therefore be integrated into the experiments that generate the headline results. A disconnected fuzzy component is insufficient for ASOC positioning.
