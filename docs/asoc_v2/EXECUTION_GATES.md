# ASOC V2 Execution Gates

These are hard stop conditions. A later stage cannot be treated as scientifically valid if an earlier hard gate fails.

## H1 — Causal state integrity

PASS only if:

- natural and stego paths maintain separate histories;
- each stego state is updated with the emitted stego action;
- sender and receiver reconstruct the same passive history for every tested trace;
- passive state mismatch rate = 0 in the deterministic contract tests.

## H2 — Four-region temporal evaluation contract

Required chronological regions:

1. `cover_train`: fit Q_theta;
2. `eve_train`: fit design steganalysers;
3. `policy_validation`: tune fuzzy/control parameters and choose the operating point;
4. `sealed_test`: final evaluation only.

PASS only if no function used for model/policy selection reads `sealed_test` labels or metrics.

## H3 — Policy integration

PASS only if the headline generation path invokes the actual control policy that chooses among EMBED/COVER/PAUSE/STOP. A disconnected fuzzy-controller benchmark does not satisfy this gate.

Required comparison:

- fixed threshold;
- hand-tuned fuzzy;
- optimized fuzzy;
- detector-unaware range/arithmetic coding;
- proposed detector-constrained policy;
- at least one distribution-preserving/coupling-inspired baseline where technically valid.

## H4 — Unseen-Eve transfer

The design detector family and final unseen detector family must be disjoint by construction.

Recommended design family:

- linear/logistic;
- random forest;
- gradient boosting.

Recommended unseen family:

- neural sequence Eve;
- transformer/GRU Eve;
- temporal-GNN Eve;
- white-box diagnostic.

PASS only if unseen-Eve results are generated after policy freeze and are not used to retune the policy.

## H5 — Statistical discipline

PASS only if:

- independent unit is source/session/trajectory as appropriate;
- message seeds are reported as technical stochastic repetitions;
- cluster bootstrap 95% intervals are reported for main AUC/rate quantities;
- paired comparisons use matched units;
- multiplicity is controlled for families of inferential tests;
- transition-level metrics are explicitly labelled as such when retained.

## H6 — Formal claim discipline

PASS only if:

- the chain-rule trajectory-divergence result states its assumptions;
- model-relative and real-process claims are separated;
- mean NLL is not substituted for a pointwise divergence bound;
- empirical Eve results are not called upper bounds on the optimal adversary;
- security conclusions remain conditional on tested detector families and the declared threat model.

## H7 — Result provenance

PASS only if:

- all headline tables/figures are generated from `results_final/`;
- every result file records config hash, code commit, seeds and dataset manifest hash;
- no old `phase*` table is cited as evidence for ASOC V2 unless explicitly regenerated by the new protocol;
- README numbers, manuscript numbers, figures and release manifest are identical.

## H8 — Applied Soft Computing positioning

PASS only if:

- Related Work cites and contrasts recent ASOC steganography papers;
- the paper makes a soft-computing contribution rather than using fuzzy logic as a decorative component;
- optimized fuzzy/hybrid policy results are central to the evaluation;
- comparisons include capacity, detectability, synchronization and decision-policy behavior;
- the conclusion answers the constrained sequential-control problem.

## Final gate

After H1–H8 pass, rerun `Q1_SCIENTIFIC_ARTICLE_GATES(5).md`. Gate 10 remains FAIL until article, code, data, figures, README and release snapshot are mutually consistent.
